# Face Detection

A simple Face Detection project that detects human faces from images or video input using computer vision techniques.

## Features

- Detects human faces
- Simple and easy-to-use implementation
- Processes image/video input
- Highlights detected faces using bounding boxes

## Technologies Used

- Python
- OpenCV
- Computer Vision

## Getting Started

Clone the repository:

```bash
git clone https://github.com/MATHIVANAN67/Face-Detection.git
```

Navigate to the project directory:

```bash
cd Face-Detection
```

Install the required dependencies:

```bash
pip install opencv-python
```

Run the application:

```bash
python main.py
```

> Note: The Python filename may be different depending on the project structure.

## Purpose

This project is created to understand the basics of face detection and image processing using Python and OpenCV.
